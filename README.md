An entry for “Your Agent in One Emoji”: 🐙. Eight arms capture an agent coordinating many tasks and subagents in parallel, with a familiar shape that reads at a glance. The program writes exactly this one emoji to `entry.txt`, without spaces or a newline.

## Run it

Requires Node.js 22.18 or later. No dependencies are needed.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/makefun-octopus node main.ts
```

Without `MAKEFUN_OUTPUT_DIR`, the output is `/output/entry.txt`. The program creates the output directory and validates the one-character entry before writing UTF-8 text.
